# Development

## Setup

```sh
npm install
npm run dev
```

`npm run dev` runs `ray develop`, which builds the extension, loads it into
Raycast, and hot-reloads on save. `raycast-env.d.ts` is generated by `ray`
(build/develop) and is not committed.

## Scripts

| Script               | What it does                                                       |
| -------------------- | ------------------------------------------------------------------ |
| `npm run dev`        | `ray develop`                                                      |
| `npm run lint`       | `ray lint` (ESLint + Prettier + manifest/icon validation)          |
| `npm run build`      | `ray build`                                                        |
| `npm test`           | `check:data`, then compiles to `test-dist/` and runs `node --test` |
| `npm run build:data` | Regenerates the English data banks and `src/data/*.generated.ts`   |
| `npm run check:data` | Fails if generated data is stale                                   |
| `npm run publish`    | `ray publish` (Raycast Store)                                      |

## Layout

- `src/practice.tsx`: the single command (practice Form, Curriculum/History
  lists, Settings form, sounds).
- `src/logic.ts`: datasets, seeded phrase generation, sessions, metrics,
  Focus session helpers, state (de)serialization.
- `src/curriculum.ts`: `english-v1` track, lesson application, round cap,
  effective goals, progress.
- `src/focus.ts`: Focus miss bank and round history.
- `src/data.ts`, `src/data/*.generated.ts`: datasets (generated files must not
  be edited by hand).
- `data/english/`: source banks and `manifest.json`; see its README.
- `scripts/`: data generation (`extract-english-core.py` needs `wordfreq`,
  see `data/english/README.md`).
- `test/`: logic, curriculum, focus, and e2e smoke tests (no UI automation).

## Extension icon

`assets/extension-icon.png` (512×512) is rendered from `docs/icon.svg`. To
regenerate it, e.g. with librsvg:

```sh
rsvg-convert -w 512 -h 512 docs/icon.svg -o assets/extension-icon.png
```

## Storage (Raycast LocalStorage)

| Key                   | Contents                                                                |
| --------------------- | ----------------------------------------------------------------------- |
| `ngram-type-state`    | Practice state v7: settings, seeded sessions, Focus session, user goals |
| `ngram-type-progress` | Curriculum progress: current lesson, completed lessons, best WPM, mode  |
| `ngram-type-focus`    | Focus miss bank (cap 40)                                                |
| `ngram-type-history`  | Round history (cap 100)                                                 |

Hydration is defensive: corrupt or older data falls back or migrates (for
example, pre-v7 custom goals become user goals; older uncapped lesson rounds are
re-capped from the same seed).
